This repository contains the JakartaEE project, which is structured into two main modules:

1. **specification**: This module contains the specifications for the JakartaEE project.
2. **implementation**: This module contains the implementations of the JakartaEE specifications.

## Project Structure

- **pom.xml**: The main Maven POM file that defines the project structure and dependencies.
- **specification/**: Directory containing the specification module.
- **implementation/**: Directory containing the implementation module.

## Building the Project

To build the project, use the following Maven command:

```sh
mvn clean install
```

This will compile the code, run the tests, and package the modules.
